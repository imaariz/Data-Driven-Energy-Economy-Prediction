# Data-Driven Energy Economy Prediction for Electric City Buses using Machine Learning 🚍⚡

## 📌 Project Overview
This project focuses on predicting the *energy economy of electric city buses* using machine learning techniques.  
It helps improve efficiency and planning in public transport by analyzing energy consumption patterns.

## 🛠 Technologies Used
- Python
- NumPy, Pandas
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Project Structure

├── Main.py                # Main Python script ├── requirements.txt       # Dependencies ├── datasetlink.txt        # Link to dataset ├── screenshots/           # Project screenshots (add images here)

## ⚙ Installation & Setup
1. Clone this repository:
   bash
   git clone https://github.com/your-username/data-driven-energy-economy-prediction.git
   cd data-driven-energy-economy-prediction

2. Install dependencies:

pip install -r requirements.txt


3. Run the project:

python Main.py



📊 Dataset

The dataset used is available in datasetlink.txt.
Download it and place it in the project folder before running the code.
